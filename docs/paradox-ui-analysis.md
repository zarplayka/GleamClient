# Разбор локального меню Paradox 1.0.244

Проверена установленная сборка в `%APPDATA%/paradoxclient/game-ui/48239db5df7a7feb/game/`.
Оригинальные файлы не изменялись. Интерфейс поставляется как HTML/CSS/JavaScript со шрифтами;
для этого участка не потребовалось декомпилировать JVM-классы.

## Инструменты и границы проверки

REA 6.8.0, команда `analyze-javascript-application`, статически разобрала
`screens/menu/js/pages/modules.js`, `js/pages/settings.js`, `js/entrance.js`.
Полные результаты: `build/rea-analysis/paradox-menu.json`, сводка: `build/rea-analysis/summary.json`.
Исследование охватывает выбранные файлы интерфейса, а не весь клиент или его сетевой протокол.

В `shared/fonts.css` начертания зарегистрированы как разные семейства, применяемые с normal weight.
Это реальные файлы Regular, Medium, SemiBold и Bold, а не синтетическое утолщение Regular.
В TTF присутствуют кириллица, Я и ё. В таблице name указаны Paradox Sans и Paradox Client.
Файлы для запрошенного локального воспроизведения темы находятся в
`src/main/resources/assets/orion-client/fonts/paradox/`; это ресурсы установленного клиентского образца.

## Изменения Orion

Темы Paradox используют встроенные TTF и отдельные начертания через OrionInterfaceFonts.
Кегли CSS переводятся в единицы макета множителем 660/1240; размер текстуры по-прежнему
совпадает с размером вывода × GUI scale. Три предыдущие темы используют прежний выбор шрифтов.
Карточки получили измеренные кегли, двухстрочное описание, подпись категории, высоту 81 единицу
и шаг 87 единиц. Подтверждена сортировка по имени. REA и ручное чтение ресурсов используются
как свидетельства устройства оригинала; Java2D-реализация Orion остаётся собственной.

## Проверка

Прямая компиляция Java 25, проверка всех пяти тем при GUI scale 1–6, проверки областей нажатия
и анимаций в отдельном процессе. PNG создаются вызовом настоящего renderImage меню без игры.
Эти проверки не подтверждают поведение драйвера Vulkan/OpenGL в запущенном Minecraft.
