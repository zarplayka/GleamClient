    Все релизы и совместимость ↗
    1. 01

      Подготовь Minecraft

      Сверь версии Minecraft, Fabric и Java с описанием релиза. Скачать Fabric Loader

      Добавь два файла

      Положи Fabric API подходящей версии и JAR GleamClient в папку mods своего игрового профиля.

    Частые вопросы

    Это отдельный лаунчер?+

    Нет. GleamClient устанавливается как клиентский мод на Fabric. Можно использовать привычный лаунчер с подходящим профилем Minecraft Java Edition.

    Какая версия Minecraft нужна?+

    Версии Minecraft, Fabric и Java указаны в описании каждого релиза.

    Подойдёт для Windows, macOS и Linux?+

    Основной клиент работает на Java и Fabric. Интеграция медиаплеера использует Windows-компоненты; на других системах часть возможностей может быть недоступна.

    Как открыть чат с другом?+

    Войди в аккаунт GleamClient и отправь заявку в разделе «Друзья». После принятия заявки переписка появится во вкладке «Чат».

    Будут ли другие игроки видеть косметику?+

    Для этого у другого игрока должна быть совместимая версия GleamClient и доступ к онлайн-сервису косметики. Доступность сервиса зависит от подключения.

    Можно ли играть на любом сервере?+

    Перед подключением проверь правила конкретного сервера. Некоторые серверы ограничивают визуальные модули, отображение информации и другие клиентские функции.
