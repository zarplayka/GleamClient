1. Оператор и область действия

Оператор персональных данных и владелец проекта GleamClient: Швайцер Владислав Витальевич, самозанятый, ИНН 553404561370. Проект также использует обозначение ZARPLAY. Контакт для связи с администрацией: Discord проекта. Новости проекта размещаются в Telegram.

Эта политика описывает сайт GleamClient, сервис косметики, каталог конфигураций и сетевые мини-игры GleamClient. Обработка производится с использованием программных средств. Пользователи сайта, игроки и лица, обращающиеся в поддержку, могут быть субъектами персональных данных.

Политика не регулирует самостоятельную обработку данных Minecraft-серверами, Microsoft, GitHub, Discord, Telegram и другими сторонними сервисами.

2. Посещение сайта

Для передачи страницы сервер получает IP-адрес, время запроса, адрес запрошенного ресурса и технические HTTP-заголовки, которые отправляет браузер. Эти сведения нужны для доставки файлов и защиты инфраструктуры. Хостинг и программное обеспечение сервера могут обрабатывать технические сведения при диагностике ошибок.

На сайте доступны вход и регистрация аккаунта GleamClient. Для чтения главной страницы регистрация не требуется. Рекламных трекеров и систем аналитики нет; шрифты, изображения и скрипты загружаются с сервера GleamClient. При входе или регистрации устанавливается необходимая для авторизации cookie __Host-orion_session: она защищена атрибутами Secure, HttpOnly и SameSite=Strict, действует до семи суток и удаляется при выходе. Она не используется для рекламы. При ручном выборе языка в localStorage сохраняется только настройка языка, чтобы применить её при следующем посещении. В sessionStorage до закрытия вкладки сохраняется последнее имя аккаунта для отображения меню во время проверки сеанса. При первом открытии язык определяется по настройкам браузера.

Аккаунт сайта

Для аккаунта сайта сохраняются имя пользователя, его нормализованный вариант, хеш пароля с солью, дата создания и адрес электронной почты, если он указан. Адрес используется для подтверждения почты, восстановления аккаунта и уведомления о сбросе пароля. Для доставки этих писем Яндекс Почта получает адрес получателя и содержимое письма. GleamClient хранит хеши одноразовых ссылок и сроки их действия. Пароль передаётся по HTTPS, обрабатывается для проверки и не сохраняется в открытом виде. Для входа хранятся хеши случайных токенов сессий, CSRF-токены и сроки действия. Для списка активных сеансов также сохраняется название браузера или клиента, если его удалось определить. Для профиля хранятся его идентификатор, загруженный аватар и имена Discord и GitHub. При подтверждении контакта GleamClient обменивает одноразовый код с выбранным сервисом и получает идентификатор и имя профиля. Токен доступа используется для этого запроса и не сохраняется. Если пользователь открыл профиль по ссылке, посетителям доступны идентификатор, ник, аватар, дата регистрации и контакты. При оценке профиля сохраняется связь голоса с аккаунтом GleamClient, а посетители видят только общие счётчики. При публикации комментария сохраняются его текст, время и автор. На открытом профиле видны текст, время и ник автора комментария. Удалить комментарий может его автор или владелец профиля. Данные нужны для регистрации, проверки пароля, сохранения входа и выхода из аккаунта. Это отдельный аккаунт сайта, который не подтверждает владение аккаунтом Minecraft. Если через сервис создаётся заявка на Plus, сохраняются её идентификатор, сумма, валюта, статус и время создания; при ручном предоставлении доступа — срок действия и запись о выдаче. Заявка не означает проведённый платёж. Данные аккаунта хранятся до его удаления, прекращения цели обработки или утраты законного основания; истёкшие сессии очищаются при создании новых. Для базы аккаунтов также используются резервные копии со сроком хранения 30 дней.

3. Онлайн-функции клиента

  • Косметика и присутствие. Сервис получает игровой UUID, никнейм, параметры нимба и крыльев, идентификатор эмоции и время её запуска, сведения об онлайн-присутствии и UUID игроков, для которых запрашивается отображение косметики. Они нужны для синхронизации внешнего вида и статусов.
  • Проверка сессии. Обрабатываются публичный ключ, одноразовая проверочная строка, подпись и служебные идентификаторы проверки. Сервер хранит хеш токена сессии и срок действия, а не сам токен в открытом виде. При проверке владения игровым аккаунтом используются сервисы сессий Mojang/Microsoft; пароль Microsoft передавать администрации GleamClient не требуется.
  • Каталог конфигов. При публикации сервер хранит название, никнейм и UUID автора, переданные настройки, даты создания и обновления, версию, счётчик скачиваний. Для учёта скачиваний сохраняется связь идентификатора конфига с UUID игрока. Локальное сохранение профиля само по себе не публикует его в каталоге.
  • Баскетбол и футбол. Для комнаты обрабатываются UUID участников, код комнаты, состав и готовность, позиции в мини-игре, состояние мяча, действия и счёт. Они нужны для совместной игры.
  • Защита API. IP-адрес, маршрут запроса и время обращения используются для ограничения частоты запросов. Журналы API могут содержать IP-адрес, время, URL, статус ответа и технические заголовки.
  • Обращения. При связи через Discord, GitHub или другие каналы обрабатываются имя или идентификатор вашего профиля, текст сообщения и приложенные вами материалы — для ответа и решения вопроса.

Настройки, аккаунты и иные файлы, остающиеся только на устройстве, не становятся серверными данными лишь потому, что установлен GleamClient. Не добавляйте персональные сведения, чужие данные, пароли или токены в названия публикуемых конфигов и сообщения поддержки.

4. Цели и правовые основания

Данные используются для предоставления запрошенных онлайн-функций, идентификации игровой сессии, синхронизации косметики, публикации и получения конфигов, организации мини-игр, обработки обращений и защиты сервиса от злоупотреблений.

Основания обработки определяются её целью: исполнение соглашения с пользователем в необходимом для выбранной функции объёме, выполнение требований закона, защита законных интересов оператора и пользователей при соблюдении их прав, а там, где требуется, — отдельное согласие. Установка клиента или просмотр сайта не считаются согласием на любую обработку либо на распространение персональных данных.

Если для новой функции потребуется согласие, оно должно запрашиваться отдельно до соответствующей обработки. Эта политика не заменяет такое согласие. Права несовершеннолетних и участие их законных представителей определяются применимым законодательством.

5. Видимость и сторонние сервисы

Онлайн-статус, косметика и эмоции доступны совместимым клиентам других игроков, запрашивающим эти сведения. Участники мини-игры получают состояние своей комнаты. Название, автор, UUID автора, метаданные и настройки опубликованного конфига доступны через общий каталог. Публикация конфига — отдельное действие пользователя; не помещайте в него информацию, которую не хотите раскрывать. Иные сведения не предназначены для публичного доступа.

Инфраструктура хостинга обрабатывает сведения, необходимые для работы сервиса. Передача и доступ к данным допускаются при наличии предусмотренного законом основания; возможна передача по законному требованию уполномоченного органа.

Переходы на GitHub, Discord, Telegram, Fabric и Modrinth открывают сторонние сервисы. Эти организации обрабатывают сведения по собственным правилам; их инфраструктура может находиться за пределами России. Переход по ссылке сам по себе не является согласием на передачу администрацией GleamClient всей информации о пользователе. Подключение новых обработчиков и трансграничная передача требуют соблюдения применимых процедур; эта политика не заменяет их.

6. Хранение и защита

Одноразовая проверочная строка действует 60 секунд, игровая сессия — до 24 часов. Истёкшие записи удаляются при служебной очистке. Без обновления присутствия игрок перестаёт считаться онлайн через 90 секунд; это не означает удаления записи профиля.

Записи профилей, косметики и опубликованных конфигов автоматически не удаляются только из-за отсутствия игрока. Они хранятся, пока необходимы для соответствующей функции, и подлежат удалению при достижении цели обработки, утрате правового основания или удовлетворении законного требования об удалении. Сведения о комнатах мини-игр находятся в оперативной памяти и удаляются при очистке комнаты или перезапуске сервиса.

Журналы API ротируются по размеру: архив до 10 МиБ, не более пяти архивных файлов; возраст записей зависит от нагрузки и настроек ротации. Резервные копии базы удаляются по мере истечения 30-дневного срока хранения. После удаления из рабочей базы сведения могут оставаться в защищённых резервных копиях до их ротации; при восстановлении должны повторно применяться выполненные требования об удалении.

Используются HTTPS, проверка подписей, ограничение запросов, разграничение доступа к серверу и закрытые резервные копии. Абсолютную защищённость нельзя гарантировать. Доступ к рабочим данным предоставляется только в объёме, необходимом для администрирования и поддержки.

7. Ваши права и обращение

Вы можете запросить сведения об обработке своих данных, их уточнение, блокирование или удаление в предусмотренных законом случаях, отозвать ранее данное согласие и обжаловать обработку в уполномоченный орган или суд. Отзыв согласия не отменяет обработку, для которой сохраняется иное законное основание.

Для обращения свяжитесь с администрацией через Discord проекта, укажите, что вопрос касается персональных данных, и запросите личный канал связи. Не размещайте документы, токены и другие конфиденциальные сведения в общедоступном чате или публичной GitHub-задаче. Для предотвращения удаления чужих данных администрация может запросить соразмерное подтверждение принадлежности игрового профиля. Пароли и секретные ключи не нужны.

Обращения рассматриваются в сроки, установленные применимым законодательством. Удаление данных может прекратить доступность связанных онлайн-функций. Можно прекратить новые обращения к сервису, отключив соответствующую функцию, выйдя из клиента или удалив мод; уже сохранённые серверные данные этим автоматически не удаляются.

Нормативная основа: Федеральный закон № 152-ФЗ «О персональных данных». Обработка должна также учитывать иные обязательные нормы, применимые к конкретной ситуации.
