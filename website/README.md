# Сайт GleamClient

Публичный адрес: https://gleamclient.xyz

Статический фронтенд без сборщика и внешних библиотек. Аккаунты подключены к существующему серверному API через `/api/*`; описание — в `server/site/README.md`. Контент и шрифты размещены локально. Изменения сайта не требуют сборки Java-мода.

## Локальный просмотр

Из корня проекта: `npx --yes http-server website -p 4173 -c-1`

Откройте http://localhost:4173. Для проверки JavaScript: `node --check website/app.js`.

## Содержимое

- `index.html` — страница, функции клиента, установка и вопросы
- `style.css` — адаптивный дизайн, локальные шрифты и состояния элементов
- `app.js` — темы демонстрации, вкладки функций и мобильная навигация
- `auth.html`, `auth.js` — центральная форма входа/регистрации, состояние аккаунта и выход; API существующего сервиса, без локального хранения паролей и токенов
- `assets/SOURCES.md` — источники официальных изображений Minecraft и флагов; сторонние изображения не входят в лицензию GleamClient
- `i18n.js` — полный английский перевод, определение языка браузера и переключение без перезагрузки; при изменении русского текста синхронизируйте словарь
- `privacy.html`, `terms.html` — политика конфиденциальности и пользовательское соглашение, редакция 04.11.2026; при изменении обработки данных или владельца тексты нужно актуализировать
- `assets/interface-0.png`, `assets/interface-4.png` — настоящий Java2D-рендер тёмного и светлого меню текущего клиента
- `assets/orion-badge.png`, `assets/basketball.png` — ресурсы проекта
- `assets/onest-*.ttf` — Onest, лицензия в `assets/OFL.txt`
- `assets/social.png` — превью сайта для ссылок
- `Caddyfile` — отдельный virtual host, дополняет существующие сервисы

В блоке «GleamClient в игре» показаны два игровых скриншота с выключенными и включёнными модулями. Кнопка скачивает `gleamclient.jar` из последнего публичного GitHub-релиза. При публикации прикладывайте проверенный файл с этим именем и указывайте совместимость в описании релиза.

## Размещение

Файлы `index.html`, `privacy.html`, `terms.html`, `auth.html`, `style.css`, `i18n.js`, `app.js`, `auth.js` и каталог `assets` размещены в `/var/www/orion-client`. Это символическая ссылка на текущий релиз в `/var/www/orion-client-releases/`: обновления переключаются атомарно, предыдущие релизы сохраняются для отката. Блок из `Caddyfile` добавлен в `/etc/caddy/Caddyfile` с проверкой `caddy validate` перед reload. Существующие virtual hosts и API сохранены. Caddy автоматически обслуживает HTTPS.

Перед обновлением сохраняйте копию текущего каталога сайта и Caddyfile. После загрузки проверяйте `caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile` и выполняйте `systemctl reload caddy`. SSH-ключи находятся вне проекта и сайта.

## Языки

Доступны русский и английский. По умолчанию выбран «Системный»: используется первый поддерживаемый язык из navigator.languages, при отсутствии совпадений — английский. Ручной выбор хранится в localStorage под ключом orion.language. Выбор «Системный» удаляет сохранённую настройку. При запрете localStorage переключение работает в текущей вкладке. Изменение языка браузера применяется автоматически в системном режиме.

Меню языка использует собственный доступный listbox с флагами; native select остаётся fallback без JavaScript. Клавиши: стрелки, Home/End, Enter, Escape. По умолчанию по-прежнему выбран системный язык.
