# Orion Client для Minecraft 1.21.4

Первая тестовая сборка порта. Включает водяной знак Orion с ником и FPS. Правый Shift открывает настройки HUD и перенесённых эффектов. Доступны пять стилей TargetESP, круг прыжка, след игрока, след снарядов, мировые частицы и контур блока. Добавлены зум на C, подмена ника и префикса, фильтр и подсветка чата, FullBright и отключение погоды. Вторую клавишу зума можно назначить в управлении Minecraft. Псевдоним, префикс и списки слов задаются в `config/orion-client-1.21.4.json`.

Команда сборки запускается из корня репозитория.

```powershell
.\gradlew.bat -p versions/1.21.4 build
```

Gradle запускается на JDK 25 из основного проекта, а мод компилируется под Java 21. Готовый JAR появляется в `versions/1.21.4/build/libs`. Для запуска нужны Minecraft 1.21.4, Fabric Loader 0.19.5 и Fabric API для 1.21.4.
